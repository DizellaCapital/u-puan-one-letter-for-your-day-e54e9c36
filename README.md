## The letter

> **Z**

Behind it sits one hidden word: **zero sleep**. The day in a single letter — deadpan, vivid, and true. Z is sleep itself in cartoon language (Zzz), the last letter of the alphabet, and the one letter nobody has to decode: everyone has lived a zero-sleep day.

## How it works

`main.py` (stdlib only) writes the letter `Z` to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is exactly one letter A–Z, and verifies the write by reading it back. The entry file is exactly 1 byte, with no trailing newline.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
